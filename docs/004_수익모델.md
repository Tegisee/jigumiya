# 004. 수익 모델

## 핵심: 쿠팡 파트너스 Affiliate 단일 전략

### 수수료 구조
- 쿠팡 파트너스 수수료: 3~10% (카테고리별 상이)
- 유저가 "지금 구매하기" 클릭 → 파트너스 링크 경유 → 구매 시 자동 수취

### 현실적 진행 순서
1. **앱 완성 + 파트너스 문구 삽입** — "이 포스팅은 쿠팡 파트너스 활동의 일환으로..."
2. **iOS 앱스토어 먼저 출시** — 실사용자 확보 (심사 1~3일)
3. **수동 affiliate 링크로 유입** — API 없이 수동 변환 링크 사용
4. **15만원 누적 달성** → 최종승인 신청
5. **API 키 발급** → 앱 업데이트 (자동 딥링크 변환 활성화)
6. **Android 출시** — Google Play 비공개 테스트 14일 + 테스터 12명 필요

### 배포 전략
- **iOS 우선**: 심사 기간 짧고, 테스터 요건 없음
- **Android 후순위**: 비공개 테스트(14일 이상) + 테스터 12명 opt-in 필요 → 시간 소요
- **iOS에서 15만원 먼저 달성** → API 키 확보 후 양 플랫폼 업데이트

## 파트너스 ID
- 개발자 ID (유저 ID 아님)
- 유저는 쿠팡 로그인 불필요
- 링크에 개발자 파트너스 ID 포함 → 구매 시 자동 입금

## 가입 정보
- URL: partners.coupang.com
- 조건: 사업자 등록 불필요, 개인 가능
- 최종승인 조건: 누적 수익 15만원 달성 후 신청
- 주의: 수익 발생 시 세금 신고 필요 (기타소득 or 사업소득)
- 현재: 가입 완료, 최종승인 전 (수익 15만원 미달성)

## 클릭 유도 전략
- 모든 상품 링크 → 파트너스 링크로 변환 (API 키 발급 후 자동, 현재는 수동)
- 알림 클릭 → 앱 상세화면 → "지금 구매하기" → 쿠팡
- 바로 쿠팡으로 보내지 않고 상세화면 경유 (체류시간 확보)

## 출시 전 필수: 파트너스 안내 문구
앱 내에 아래 문구 삽입 필수 (파트너스 정책 + 앱스토어 심사):
> "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- 위치: 설정 화면 하단 또는 상세 화면 구매 버튼 근처
- 출시 직전에 추가 예정

## 코드 구현 현황
- services/coupangApi.ts — HMAC 서명 + 딥링크 생성 API (API 키 발급 후 활성화)
- components/CoupangScraper.tsx — WebView 기반 상품 정보 스크래핑 (즉시 사용)
- services/config.ts — EXPO_PUBLIC_COUPANG_ACCESS_KEY/SECRET_KEY 환경변수
