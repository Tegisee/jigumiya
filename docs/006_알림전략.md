# 006. 알림 전략

## 원칙
- 귀찮지 않게, 하지만 클릭하고 싶게
- 알림 많으면 앱 삭제 유발

## 알림 조건
- 가격 체크 시 직전 대비 하락 → 알림 발송
- 가격 변동 없음 → 알림 없음
- 가격 상승 → 알림 없음
- 매일 한국시간 21시 전후 1회 무조건 발송 (저녁 구매 전환율 최고)

## 알림 설정
- 전체 ON/OFF 토글 하나만 (세분화 없음)

## 푸시 알림 문구
- "[지금이야] 🎉 찜해둔 상품이 목표가 밑으로 떨어졌어요!"
- "[지금이야] 드디어 때가 왔습니다. 결제하러 가실 시간이에요! 💳"
- "[지금이야] 헉! 방금 가격 내려갔어요. 언제 다시 오를지 몰라요! 📉"
- "[지금이야] 잊고 계셨죠? 찜해둔 그 아이템, 지금이 줍줍할 타이밍!"
