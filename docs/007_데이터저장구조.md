# 007. 데이터 저장 구조

## 2단계 방어
1. AsyncStorage (로컬) - 앱 껐다 켜도 유지
2. Firebase Firestore (클라우드) - 익명 ID로 백업

## TrackedItem 타입
```typescript
interface TrackedItem {
  id: string
  url: string
  productName: string
  currentPrice: number
  targetPrice: number
  thumbnail: string
  priceHistory: { date: string; price: number }[]
  createdAt: number
}
```

## Zustand 스토어
- isWowMember: boolean
- trackedItems: TrackedItem[] (최대 20개)
- addItem / removeItem / toggleWowMember / updateTargetPrice

## 데이터 유실 케이스
- 앱 삭제 후 재설치 → 익명 ID 변경 → 복구 불가
- Phase 3에서 카카오/애플 로그인으로 복구 옵션 선택적 제공
