# 001. 프로젝트 개요

## 앱 기본 정보
- 앱 이름: 지금이야 (Jigumiya)
- 번들 ID: com.jigumiya.app
- 슬로건: "기다렸다, 지금이야"
- 컨셉: 로그인 없는 투명 인간 앱. 심플하고 빠르게, CS 없이 돌아가는 완전 자동화 유틸리티

## 핵심 기능
쇼핑몰 앱에서 '공유하기'를 눌렀을 때 URL을 받아 저장하고,
유저가 설정한 목표가 도달 시 푸시 알림을 보내는 초간단 가격 추적 유틸리티 앱.

## 절대 원칙 (절대 어기지 말 것)
1. 로그인/회원가입 UI 없음
2. 타 판매자 검색 로직 절대 금지
3. 커뮤니티/포인트/소셜 기능 없음
4. 직접 크롤링 금지 (쿠팡 파트너스 API만 사용)
5. 광고(AdMob) 없음
6. 문의하기 없음
7. 상품 등록 최대 20개 제한

## 타겟
- 물건을 장바구니에 담아두고 가격이 떨어지길 기다리는 일반 대중
- 기존 가격 비교 앱의 무거운 UX를 탈피한 '백그라운드 비서형' 유틸리티 원하는 유저

## 개발 환경
- 맥미니 (Apple Silicon)
- Claude Code v2.1.72 (Max Plan)
- Node.js v25.6.1 / npm 11.9.0
