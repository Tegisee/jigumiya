# 003. 디자인 시스템

## 컬러
- background: #000000
- card: #1A1A1A
- primary: #00E5CC (비비드 민트)
- text: #FFFFFF
- subtext: #888888
- border: #2A2A2A

## 컨셉
- 비비드 민트 + 블랙 조합
- 경쟁 쇼핑앱 대부분이 빨간색 → 차별화
- 앱스토어에서 눈에 띔
- 다크모드 기본 (라이트모드 없음)
- 심플하고 빠른 UX, 불필요한 애니메이션 최소화

## 화면 목록
1. 메인 리스트 화면 (홈 탭)
   - 헤더: "지금이야"
   - 와우 회원 토글 (상단)
   - 상품 카드 FlatList
   - FAB(+): URL 붙여넣기 모달
2. 목표가 입력 모달
   - URL 입력 (readOnly - Share Intent로 자동 입력)
   - 목표가 숫자 입력
   - 저장/취소 버튼
3. 상품 상세 화면
   - 뒤로가기 + 삭제 버튼
   - 썸네일 + 상품명 + 출처 + 등록일
   - 가격 그리드 2x2 (현재가/목표가/최고가/최저가)
   - 30일 가격 변동 차트
   - "지금 구매하기" 버튼 (파트너스 링크)
4. 설정 화면 (설정 탭)
   - 와우 회원 토글
   - 개인정보처리방침
   - 버전 정보

## 상품 카드 구성요소
- 썸네일
- 상품명
- 현재가 / 목표가
- 달성률 % + 프로그레스바
- Sparkline 차트 (높이 60, 민트 컬러)
- 탭 시 상세화면 이동
