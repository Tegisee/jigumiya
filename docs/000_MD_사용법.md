## CLAUDE.md (메인) 역할
- 전체 작업 항목을 번호순으로 관리
- 각 항목의 상태를 표시: ✅ 완료 / 🔄 진행중 / ⬜ 대기 / ⏸ 보류
- 각 항목에 해당하는 sub MD 파일명 연결
- Phase 1/2/3 큰 틀의 로드맵 포함

## sub MD 역할
- 각 작업 항목의 상세 내용, 플로우, 결정사항, 코드 스펙 포함
- 작업 완료 후에도 삭제하지 않고 이력으로 보존
- 새 기능 추가 시 새 번호로 sub MD 생성

## 새 대화창 시작 방법
1. Claude Code 실행: ji
2. 아래 명령어 입력:
   "docs/000_MD_사용법.md 와 CLAUDE.md 읽고,
   오늘 진행할 작업 [번호_작업명.md] 도 읽어줘.
   읽고 나면 현재 상태 요약하고 바로 시작해."

## 새 기능 추가 방법
1. 기획자(나)가 새 기능 아이디어 제안
2. CLAUDE.md의 작업 리스트에 적절한 순번으로 추가
3. docs/[번호]_[기능명].md 생성 (상세 스펙 작성)
4. 해당 작업 대화창에서 sub MD 읽고 작업 시작

## 작업 완료 후
1. 해당 sub MD에 완료 내용 + 변경사항 업데이트
2. CLAUDE.md 상태 ✅ 로 변경
3. 다음 작업 sub MD 확인 후 새 대화창에서 시작

## 주의사항
- 한 대화창에서 너무 많은 작업 하지 말 것 (이미지 100장 제한)
- 작업 단위는 sub MD 1개 = 대화창 1개 원칙
- 스크린샷은 꼭 필요한 것만 첨부
- 에러 메시지는 텍스트로 복사해서 붙여넣기 (이미지 X)

## 기능 마무리 규칙

### 마무리 시그널
대화 중 아래 말이 나오면 자동으로 마무리 절차를 진행한다:
- "이번 기능 마무리하자"
- "다음 대화창으로 넘어가자"
- "여기서 마무리하고 다음으로 넘어가자"

### 마무리 절차 (자동)
1. 현재 작업 sub MD에 완료 내용 + 변경사항 업데이트
2. CLAUDE.md 작업 상태 업데이트 (🔄 → ✅)
3. 다음 작업 sub MD 확인
4. 아래 형식으로 새 대화창 안내 출력

### 출력 형식
━━━━━━━━━━━━━━━━━━━━━━━━
✅ [번호_작업명] 마무리 완료
📋 다음 대화창에서 Claude Code(ji) 실행 후 아래 입력:
"docs/000_MD_사용법.md 와 CLAUDE.md 읽고,
[다음번호_다음작업명.md] 도 읽어줘.

## Claude AI 대화창 컨텍스트 유지 방법

### 문제
Claude AI 새 대화창은 이전 대화 내용을 기억하지 못해 매번 초기화됨.

### 해결방법
새 대화창 시작 시 CLAUDE.md 내용을 붙여넣기해서 컨텍스트 전달.

### 터미널에서 CLAUDE.md 클립보드 복사
cd ~/jigumiya
cat CLAUDE.md | pbcopy

### Claude AI 대화창 시작 템플릿
아래는 현재 프로젝트 컨텍스트야. 읽고 나서 질문에 답해줘.

[CLAUDE.md 붙여넣기]

### 정리
- Claude Code → 개발 작업 (MD 파일 직접 읽음)
- Claude AI → 기획/전략/질문 (CLAUDE.md 붙여넣기로 컨텍스트 전달)
- 작업 마무리 시 → Claude Code에서 MD 업데이트 → Claude AI에서 메모리 업데이트 요청

## 대화창 마지막 규칙

### 절차
