# 002. 기술 스택

## 프레임워크
- React Native + Expo SDK 55
- EAS Build 기준 (Expo Go 사용 금지 - Share Intent 작동 안 함)
- TypeScript

## 상태관리
- Zustand + AsyncStorage persist
- isWowMember: boolean (초기값 false)
- trackedItems: TrackedItem[] (최대 20개)

## 데이터베이스
- Firebase Firestore (클라우드 백업)
- Firebase Anonymous Auth (기기별 고유 ID)
- AsyncStorage (로컬 1차 저장)
- Firebase 초기화 실패 시 AsyncStorage로 자동 폴백

## 네비게이션
- Expo Router (파일 기반 라우팅)
- 하단 탭바: 홈 | 설정

## 차트
- react-native-gifted-charts (Sparkline + LineChart)
- react-native-svg (gifted-charts 의존성)

## 공유 수신
- expo-share-intent (Share Intent)

## 알림
- Firebase Cloud Messaging (FCM) - Phase 2

## 패키지 버전 (주요)
- expo: ~55.0.4
- react: ^19.2.4 (peer dependency로 19.2.0→19.2.4 업그레이드)
- react-native: 0.83.2
- zustand: ^5.0.11
- @react-native-async-storage/async-storage: ^2.2.0
- react-native-gifted-charts: ^1.4.75
- expo-share-intent: 최신버전
- expo-router: ~55.0.3
