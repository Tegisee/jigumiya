# 005. UX 플로우

## 상품 등록 (2가지)
1. Share Intent: 쿠팡 앱 → 공유하기 → 지금이야 → 목표가 입력 → 저장
2. 수동: 지금이야 앱 → + 버튼 → URL 붙여넣기 → 목표가 입력 → 저장

## 알림 → 구매 플로우
1. 백그라운드 가격 체크 (Phase 2)
2. 목표가 이하 감지 → 푸시 알림
3. 알림 탭 → 지금이야 앱 상세화면 딥링크
4. "지금 구매하기" 탭 → 파트너스 링크로 쿠팡 이동
5. 구매 → 수수료 수익

## 상품 등록 제한
- 최대 20개
- 초과 시 "가장 오래된 상품을 삭제하고 추가하시겠습니까?" Alert
