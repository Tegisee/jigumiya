# 010. 쿠팡 파트너스 API

## 상태: ⏸ 보류 (15만원 달성 → 최종승인 후 진행)

## 코드 구현 완료
- services/coupangApi.ts (HMAC 서명 + 딥링크 생성)
- services/productMeta.ts (OG 태그 기반 상품 정보 파싱)
- services/config.ts (API 키 초기화)
- API 키 발급 후 .env 설정만 하면 활성화

## 활성화 조건
1. 수동 affiliate 링크로 15만원 누적 수익 달성
2. partners.coupang.com에서 최종승인 신청
3. 승인 완료 후 API 키(ACCESS_KEY / SECRET_KEY) 발급
4. .env에 EXPO_PUBLIC_COUPANG_ACCESS_KEY / SECRET_KEY 설정
5. 앱 업데이트 배포 → 자동 딥링크 변환 활성화

## 가입 정보
- URL: partners.coupang.com
- 조건: 개인 가능, 사업자 불필요
- 현재: 가입 완료, 최종승인 전 (수익 15만원 미달성)

## 구현할 기능 (API 키 발급 후)
1. URL 등록 시 자동 딥링크 변환 (파트너스 링크)
2. 상품 정보 자동 파싱 (상품명, 썸네일, 현재가) — 현재도 OG 태그로 동작
3. 주기적 가격 업데이트 (Phase 2)

## API 활용 계획
- 딥링크 생성: POST /v2/providers/affiliate_open_api/apis/openapi/v1/deeplink
- 상품 정보 조회: 등록 시 1회
- 가격 체크: 하루 3회 (Phase 2)
