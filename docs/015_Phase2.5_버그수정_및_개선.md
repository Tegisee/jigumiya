- Claude AI + Gemini AI 3자 검토 완료

## 원칙 변경

## 작업 목록

### 1. [버그] GitHub Actions + FCM 알림 디버깅
- 상태: ✅
- 문제: 08시/14시 KST 알림이 오지 않음
- 확인사항: Actions 실행 로그, FCM 토큰, 발송 로직

### 2. [버그] 저장 후 네비게이션 수정
- 상태: ✅
- 문제: 상품 저장 후 쿠팡 페이지로 이동됨 (앱 내 홈/상세로 복귀해야 함)

### 3. [개선] 가격변동 그래프 + 안내문구
- 상태: ✅
- 데이터 1개일 때 "가격 데이터 수집 중" 대신 의미 있는 표시
- 무변동 시: "최근 OO일간 가격변동이 없었습니다"

### 4. [개선] 상품추가 시 현재가 표시 + 목표가 추천
- 상태: ✅
- 링크 입력 → WebView 스크래핑 → 현재가 표시
- 수집 이력 있으면 "추천 목표가" 제안 (최근 N일 최저가 기반)

### 5. [개선] 스마트 알림 (조건별 분기)
- 상태: ✅
- 가격 하락: "OO원 → OO원! 목표가까지 OO원"
- 목표가 도달: "기다렸다, 지금이야!"
- 7일 무변동: "OO일째 같은 가격입니다"
- 최저가 갱신: "역대 최저가!"
- 주의: "실시간" 표현 금지, "매일 3회 확인" 명시

### 6. [개선] 파트너스 필수 문구 노출
- 상태: ✅
- 상품 리스트/상세 화면에 문구 추가
- "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."

### 7. [신규] 온보딩 화면
- 상태: ✅
- 최초 실행 시 4단계 온보딩
- 1) 앱 소개 2) 쿠팡 이동 방법 3) 공유하기 방법 4) 목표가 설정 + 알림
- 와우/일반 선택 토글 (와우가 스크래핑 가능 여부 확인 후 결정)
- 기존 예시 상품 화면 제거

### 8. [신규] 가격 알림 공유 기능
- 상태: ✅
- 가격 하락 시 "친구에게 공유" 버튼
- 제휴 딥링크 + 파트너스 문구 필수 포함

### 9. [신규] 위시리스트 공유 기능
- 상태: ✅
- 내 추적 상품 목록을 링크로 공유
- 받는 사람이 제휴 링크로 구매 시 수익 발생

### 10. [신규] 골드박스/특가 섹션
- 상태: ✅
- 쿠팡파트너스 API 골드박스 엔드포인트 확인 필요
- 있으면: 홈 화면에 "오늘의 특가" 섹션 추가
- 없으면: 다음 Phase로 이관

## 비용/리스크 체크
- 검색 API rate limit: 분당 10~50회 추정, 확인 필요
- 골드박스 API: 존재 여부 확인 필요
- 와우가 스크래핑: 비로그인 WebView에서 가능한지 확인 필요
- 스토어 심사: 독창적 기능(가격 추적 그래프, 스마트 알림)으로 리젝 방어

## 참고
- 쿠팡 외부 플랫폼(네이버, 11번가 등) 가격 비교 절대 금지
- 가격 데이터는 "조회 시점 기준" 명시, "실시간" 표현 금지
- AI 가격 예측 기능 금지
